# Java OOP Project Collection

This repository contains Java projects implemented using Object-Oriented Programming (OOP) principles. Each project features abstract classes, inheritance, validation, and reporting features.

## 📁 Project 1: Mission Management System

Manages military and humanitarian missions with personnel and resource assignments.

### Features
- Abstract class: `Mission`
- Subclasses: `ReconMission`, `RescueMission`, `CombatMission`, `HumanitarianMission`
- Personnel and resource validation
- Task allocation and mission tracking
- Mission report generation

## 📁 Project 2: Land Management System

Handles different land types with ownership and zoning validation.

### Features
- Abstract class: `Land`
- Subclasses: `AgriculturalLand`, `ResidentialLand`, `CommercialLand`, `IndustrialLand`
- Ownership and zoning compliance checks
- Tax calculation
- Detailed land reports

## 📁 Project 3: Nursery School Management System

Manages student enrollment, teacher assignments, and class activities.

### Features
- Abstract class: `NurseryClass`
- Subclasses: `BabyClass`, `MiddleClass`, `TopClass`
- Enroll students with age and capacity validation
- Track class progress and activities
- Generate class summary reports

## 🛠 Technologies Used
- Java 17+
- IntelliJ IDEA (Recommended)
- OOP Concepts (Abstract Classes, Inheritance, Polymorphism)
- Collections (`ArrayList`)
- Simple input/output handling
